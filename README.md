## 📖 Sobre o projeto

Esta aplicação é uma landing page introdutória sobre **Frameworks CSS**, com foco no **Tailwind CSS**. A página apresenta os principais conceitos da abordagem utility-first, os benefícios do framework e exemplos práticos de componentes responsivos.

O projeto foi desenvolvido com base nos conteúdos da **Aula 07 — Frameworks CSS** e corresponde à **Atividade 02** da disciplina de Front-End (SENAI).

### ✨ Funcionalidades

- 🧭 **Navbar fixa** com links de navegação e botão de acesso
- 🚀 **Seção hero** com gradiente e call-to-action
- 📋 **Seção "Por que usar Tailwind?"** com 3 pilares:
  - Utility-First
  - Responsivo (mobile-first)
  - Consistência (tokens de design)
- 🧩 **Seção de componentes** com 4 cards temáticos (Rápido, Mobile First, Customizável, Modular)
- 🖼️ **Exemplo prático** de posicionamento com Flexbox e elementos sobrepostos
- 📱 **Totalmente responsivo**, adaptando-se a mobile, tablet e desktop
- 🦶 **Rodapé** com links de contato e redes sociais

## 🚀 Como executar

Não é necessário instalar dependências. Basta abrir o arquivo `index.html` diretamente no navegador:

```bash
# Clone ou baixe este repositório
# Em seguida, abra o arquivo:
index.html
```

Como o Tailwind é carregado via CDN (`@tailwindcss/browser@4`), o estilo é aplicado automaticamente ao abrir a página com conexão à internet.

## 📚 Aprendizados

Durante o desenvolvimento desta atividade foram praticados:

- Utilização de classes utilitárias do Tailwind CSS (`flex`, `grid`, `gap`, `p-`, `m-`, `rounded`, `shadow`, etc.)
- Breakpoints responsivos (`sm:`, `md:`, `lg:`)
- Posicionamento (`fixed`, `absolute`, `relative`) combinado com Flexbox
- Gradientes, sombras, transições e transformações com classes utilitárias
- Criação de layouts com CSS Grid e Flexbox
- Organização semântica com HTML5 (`nav`, `section`, `footer`)
